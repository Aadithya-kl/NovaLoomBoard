# NovaLoomBoard brand assets

The mark is two threads woven into an **N**: the teal thread passes under the amber one, and a four-point spark (the *nova*) sits where the amber thread begins. It sits on a rounded indigo tile, so it reads the same on light and dark backgrounds.

| File | Use |
| --- | --- |
| `logo.svg` | The master artwork (512 × 512 viewBox) |
| `icon-16.png` … `icon-1024.png` | App icon, avatars, documentation |
| `favicon.ico` | 16, 24, 32, 48, 64, 128 and 256 px in one file |
| `wordmark-light.svg`, `wordmark-light.png` | Mark and name, for light backgrounds |
| `wordmark-dark.svg`, `wordmark-dark.png` | Mark and name, for dark backgrounds |
| `social-preview.svg`, `social-preview.png` | 1280 × 640 repository social preview |

## Colours

| Name | Hex | Role |
| --- | --- | --- |
| Loom indigo | `#1A1C4B` | Tile, wordmark on light backgrounds |
| Thread teal | `#3DD6C6` | First thread |
| Nova amber | `#FFC24B` | Second thread and spark |
| Night | `#14163D` | Social preview background |
| Mist | `#F4F4FB` | Wordmark on dark backgrounds |

The wordmark is set in Segoe UI Variable Display Semibold. The SVG wordmarks fall back to Segoe UI, Inter, Helvetica Neue or Arial; use the PNGs where exact rendering matters.

## Usage

- Keep clear space around the tile of at least a quarter of its width.
- Don't recolour, rotate, stretch or outline the mark, or put it on a busy image.
- The assets are covered by the repository's MIT License. Please don't use the name or logo in a way that suggests your project is the official NovaLoomBoard.
